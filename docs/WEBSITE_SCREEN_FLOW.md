# Website Screen Flow

## Discovery Flow

1. Visitor lands on `/`.
2. Visitor reviews the product promise and visual wardrobe preview.
3. Visitor opens `/how-it-works`, `/features`, `/ai-stylist`, or `/smart-shopping`.
4. Visitor chooses `Start organizing your wardrobe`, which routes to `/signup`.

## Account Entry Flow

1. Visitor opens `/login`.
2. Visitor can move to `/signup` or `/forgot-password`.
3. Forms show clear validation-ready structure, but real auth integration is deferred to Run 2.

## Legal and Trust Flow

1. Visitor reviews `/privacy` and `/terms`.
2. Visitor can contact Clorisa from `/contact`.

## Deferred Flow

Dashboard routes are not exposed in Run 1.
