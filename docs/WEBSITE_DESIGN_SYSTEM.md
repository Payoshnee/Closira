# Website Design System

## Brand Feel

Clorisa should feel premium, clean, elegant, fashion-tech, private, and calm. The website uses warm ivory surfaces, charcoal text, champagne and rose accents, muted lavender support tones, and image-inspired editorial composition built in CSS until real visual assets exist.

## Tokens

- Background: ivory and warm white.
- Text: charcoal and muted stone.
- Accent: rose, champagne, lavender, and sage.
- Radius: restrained `8px` for cards and controls.
- Shadow: soft layered shadows for key surfaces.
- Type: system sans serif with clear hierarchy and generous line height.

## Components

- Button
- Card
- Badge
- Input
- Textarea
- Container
- Section header
- Navbar
- Footer
- Feature card
- Step card
- Visual mockup
- Empty, error, skeleton, and toast primitives

## Accessibility

- Interactive controls have visible focus rings.
- Color contrast targets WCAG AA.
- Forms include labels.
- Navigation is keyboard accessible.
- Mobile navigation uses a real disclosure state.
