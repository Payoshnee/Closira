# Roadmap

## Current Version

Version `0.0.0`: documentation and architecture bootstrap.

## Next Version

Version `0.1.0`: Phase 1 project foundation with runnable Flutter, Next.js, NestJS, FastAPI, PostgreSQL, Redis, Prisma, Docker Compose, env examples, linting, formatting, and CI.

## Upcoming AI Features

- AI auto tagging.
- Image embeddings and similar item detection.
- Outfit recommendations using owned wardrobe items.
- Smart shopping assistant.
- Virtual try-on foundation with consent and feature flags.

## Scaling Plans

- Queue-based AI processing.
- Image variant generation.
- pgvector indexing and later dedicated vector database if needed.
- CDN-backed signed image delivery.
- Admin observability for AI, storage, and usage.

## Monetization

- Free: up to 50 wardrobe items, manual outfits, basic categories, basic search.
- Premium: unlimited items, AI tagging, recommendations, calendar, analytics, similar item detection.
- Pro: virtual try-on, makeup and jewelry try-on, advanced stylist, smart shopping.
- Enterprise: boutique, brand, stylist, and affiliate integrations.

## Long-Term Vision

Closira becomes a privacy-first personal fashion memory and styling layer that connects owned wardrobe data, planning, shopping decisions, and virtual preview experiences.
